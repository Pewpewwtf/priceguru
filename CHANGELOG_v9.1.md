# PriceWatch v9.1

Исправление Wildberries HTTP 403 в облаке.

## Что изменено

- WB больше не зависит только от Node `fetch`.
- Порядок получения WB: `curl` → повтор на 403/429 → второй WB host → Node fetch → Chromium fallback.
- `curl` принудительно использует IPv4 (`-4`).
- В Docker image явно устанавливаются `curl` и CA certificates.
- Ошибка WB теперь содержит диагностику каждой попытки.
- Опционально поддерживается `WB_PROXY_URL`, но добавлять его заранее не нужно.
- Версия health endpoint: `9.1`.

## Обновление с v9

Перезапишите содержимое GitHub-репозитория файлами v9.1 и сделайте commit/push. Существующая PostgreSQL и ENV остаются прежними. Данные не удаляются.
