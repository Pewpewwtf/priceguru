# Обновление v9 → v9.1

1. Распакуйте v9.1.
2. Замените файлы в корне вашего GitHub-репозитория содержимым папки `PriceWatch_v9_1_cloud`.
3. Сделайте commit + push.
4. PostgreSQL и существующие ENV не меняйте.
5. Дождитесь успешного redeploy Timeweb.
6. Откройте `/api/health` — должно быть `"version":"9.1"` и `"database":"postgres"`.
7. Повторите добавление WB-ссылки.

Новый `WB_PROXY_URL` пока НЕ добавляйте. Он нужен только если диагностика v9.1 покажет 403 на curl, fetch и browser одновременно.
